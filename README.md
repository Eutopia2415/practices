# To Autumn · AP Literature Practice

[Open the practice quiz](https://eutopia2415.github.io/to-autumn-practice/)

A 15-question, original AP-style close-reading practice set for John Keats’s *To Autumn*. The site has answer elimination, confidence ratings, review flags, color controls, saved progress, and feedback after submission. There is no timer or sign-in.

The quiz runs entirely in the browser. Progress is stored locally in that browser; it does not sync across devices. Because grading happens in the browser, the answer key is visible to anyone who inspects the page source.

The poem is in the public domain. [Poem source](https://poets.org/poem/autumn). This practice set is not affiliated with or endorsed by the College Board.
